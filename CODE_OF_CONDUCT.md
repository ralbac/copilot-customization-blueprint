# Code of conduct

## The short version

Be useful. Be direct. Assume the other person is competent and busy.

This repository is technical documentation about a tool. Disagreement about what a tool does
is expected and should be resolved with a citation, not with volume.

## Expected behaviour

- Critique the claim, the code, or the document. Never the person.
- When you say something is wrong, say what the correct behaviour is and link the source. The
  documentation is the tie-breaker here, which is the entire reason the repository keeps a
  [source list](reference/sources.md).
- Accept that a correction to your work is a contribution, not an attack. This repository
  documents a moving target; being out of date is normal and being corrected is the process
  working.
- Keep review comments about the change. If you want to discuss a different problem, open a
  different thread or a different issue.
- Respect the scope of an issue. "While we are here" is how a one-line correction becomes an
  unreviewable pull request.

## Unacceptable behaviour

- Harassment, insults, or personal attacks, in any form.
- Demeaning someone for not knowing a feature, a term, or an official documentation page.
  Everyone starts somewhere and this repository exists for the people who are starting.
- Discriminatory language or imagery, including in commit messages, code comments, and issue
  content.
- Sexual attention or advances of any kind.
- Publishing someone's private information without permission.
- Sustained disruption: derailing threads, reopening settled decisions without new evidence,
  or relitigating scope to prevent work from finishing.
- Presenting unverified claims as established fact, particularly about security or data
  handling, and particularly after being asked for a source.

## Scope

This code applies in issues, pull requests, discussions, commit messages, and any space where
you are representing this project.

## Reporting

Report unacceptable behaviour to a maintainer. If the report concerns a maintainer, contact a
different one.

Reports are handled privately. You will get an acknowledgement, and a statement of what
happens next. Maintainers may remove comments, close threads, or block accounts, and will
explain the reason to the person affected unless doing so would expose the reporter.
